what you need

Что понадобится

  • chat ID — номер вашего личного чата с ботом. Это обязательное поле.
  • username — ваш ник в Telegram, например @ivan_petrov. Поле необязательное.
1

Откройте бота

В Telegram найдите бота {% if bot_username %}@{{ bot_username }}{% else %}Sky Habit{% endif %} или нажмите кнопку ниже.

{% if bot_url %} Открыть @{{ bot_username }} {% endif %}
2

Нажмите «Запустить»

Внизу чата нажмите кнопку «Запустить» или отправьте команду /start. Бот ответит примерно так:

Ваш chat ID: 123456789

Скопируйте только цифры — это и есть ваш chat ID. Он не меняется и не является секретом.

3

Узнайте username (необязательно)

В Telegram откройте Настройки → Профиль (в некоторых версиях — «Изменить профиль») и посмотрите поле «Имя пользователя».

Если у вас @ivan_petrov, на сайте вводите ivan_petrov — без символа @. Можно оставить поле пустым: на отправку карточек это не влияет.

4

Сохраните в профиле

Вернитесь в профиль, вставьте chat ID, при желании добавьте username, включите «Отправлять напоминания» и нажмите «Сохранить».

Перейти в профиль
Важно: не вставляйте в поле chat ID номер самого бота — напоминания не дойдут. Нужен именно номер вашего личного чата, который бот присылает в ответ на /start.

Частые вопросы

Бот не отвечает на /start

Проверьте, что вы открыли правильного бота и нажали именно «Запустить». Если сообщение отправлено, но ответа нет, подождите немного и попробуйте ещё раз. Для локального запуска проекта бот должен быть запущен на компьютере.

Где ещё можно узнать chat ID

Самый простой способ — ответ нашего бота на /start. Также можно написать стороннему боту @userinfobot: он покажет ваш ID. Главное — не путать его с ID бота Sky Habit.

Username обязателен?

Нет. Для отправки карточек достаточно chat ID. Username нужен только для удобства и отображения в профиле.

Карточки всё равно не приходят

Проверьте три вещи: chat ID состоит только из цифр, галочка «Отправлять напоминания» включена, а боту отправлена команда /start_notified. После этого нажмите кнопку отправки карточки в профиле или на странице привычки.

Можно ли указать ID группы

Да, если бот добавлен в эту группу. ID группы обычно начинается с минуса. Для личных напоминаний лучше использовать chat ID личного чата.

checklist
  • Бот открыт в Telegram
  • Отправлен /start
  • Скопирован chat ID из ответа
  • ID вставлен в профиль
  • Включена рассылка
  • Сохранено
